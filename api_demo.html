REST API Client Demo

This demo shows how to use the APIClient class to make GET and POST requests to REST APIs.

GET Request Examples

Test GET requests using the JSONPlaceholder API (a free testing API).

POST Request Examples

Test POST requests to create new resources.

File Upload Example

Test file upload functionality (simulated).

Authentication Example

Example of how to include authentication headers (will fail as expected).

Code Examples

Basic GET Request

const client = new APIClient('https://jsonplaceholder.typicode.com'); const users = await client.getRequest('/users'); console.log(users);

GET Request with Parameters

const posts = await client.getRequest('/posts', { userId: 1, _limit: 5 }); console.log(posts);

POST Request

const newPost = { title: 'My Post', body: 'Post content', userId: 1 }; const response = await client.postRequest('/posts', newPost); console.log(response);

Authenticated Request

const headers = { 'Authorization': 'Bearer your_token_here' }; const data = await client.getRequest('/protected-endpoint', {}, headers);
